# CRUD Service Design

A schema-driven approach to generating CRUD operations with automatic validation, case mapping, and query generation.

## Overview

The goal is to create a `createCrudService(schema, options)` factory that generates all standard CRUD operations from a single schema definition. This builds on three foundational pieces:

1. **Validators** - Composed from `@yamf/shared/validator` using `is` types
2. **Case Mapping** - Automatic snake_case → camelCase conversion on query results via `@yamf/shared/utils/case-mapper`
3. **Safe Query Execution** - Parameterized queries through `postgres-service`

> **Note on Case Mapping**: Template placeholders use camelCase (`:userId`, `:isActive`) to match JS data keys directly. SQL column names are written as snake_case in the template by the developer. Only the *output* from PostgreSQL needs conversion from snake_case back to camelCase.

## Schema Definition

### Enhanced Schema Format

```javascript
import { is } from '@yamf/shared/validator'

const userCrudSchema = {
  // Table configuration
  tableName: 'yamf.user',
  
  // Primary key (supports composite keys as array)
  primaryKey: 'userId',
  
  // Field definitions
  fields: {
    userId: {
      type: is.int({ positive: true }),
      column: 'user_id',        // explicit column name (optional, auto-derived)
      autoIncrement: true,      // exclude from INSERT
      primaryKey: true,         // marks as primary key
    },
    username: {
      type: is.email,
      column: 'username',
      unique: true,
      required: true,           // NOT NULL
    },
    hash: {
      type: is.base64(),
      column: 'hash',
      internal: true,           // never expose in read responses
    },
    salt: {
      type: is.base64(),
      column: 'salt',
      internal: true,
    },
    isRegistered: {
      type: is.bool,
      column: 'is_registered',
      default: false,
    },
    isActive: {
      type: is.bool,
      column: 'is_active',
      default: false,
    },
    createdAt: {
      type: is.datetime(),
      column: 'created_at',
      autoSet: 'create',        // auto-set on create
      immutable: true,          // cannot be updated
    },
    updatedAt: {
      type: is.datetime(),
      column: 'updated_at',
      autoSet: 'always',        // auto-set on create and update
    },
  },
  
  // Soft delete configuration (optional)
  softDelete: {
    field: 'deletedAt',
    column: 'deleted_at',
  },
  
  // Audit configuration (optional)
  audit: {
    createdBy: 'createdBy',
    updatedBy: 'updatedBy',
  },
}
```

### Field Properties Reference

| Property | Type | Description |
|----------|------|-------------|
| `type` | Schema | Validation schema from `is.*` |
| `column` | string | PostgreSQL column name (auto-derived if omitted) |
| `primaryKey` | boolean | Part of primary key |
| `autoIncrement` | boolean | Auto-generated by database (SERIAL) |
| `unique` | boolean | UNIQUE constraint |
| `required` | boolean | NOT NULL constraint |
| `default` | any | Default value for INSERT |
| `internal` | boolean | Never expose in API responses |
| `immutable` | boolean | Cannot be updated after creation |
| `autoSet` | 'create' \| 'update' \| 'always' | Auto-set timestamp |

## Generated Operations

### Create

```javascript
// Generated validator
const validateCreate = createValidator({
  username: userSchema.fields.username.type,
  password: is.password(),  // special handling for password fields
  isRegistered: is(is.optional, userSchema.fields.isRegistered.type),
  isActive: is(is.optional, userSchema.fields.isActive.type),
}, { name: 'CreateUser' })

// Generated query template
const createQuery = `
  INSERT INTO yamf.user (username, hash, salt, is_registered, is_active, created_at, updated_at)
  VALUES (:username, :hash, :salt, :isRegistered, :isActive, :createdAt, :updatedAt)
  RETURNING user_id, username, is_registered, is_active, created_at, updated_at
`
```

### Read (Get One)

```javascript
// Generated validator - requires at least one identifier
const validateGet = createValidator(
  is.refine(
    is.object({
      userId: is(is.optional, userSchema.fields.userId.type),
      username: is(is.optional, userSchema.fields.username.type),
    }),
    (data) => Object.values(data).some(v => v !== undefined),
    'At least one identifier is required'
  ),
  { name: 'GetUser' }
)

// Generated query template
const getQuery = `
  SELECT user_id, username, is_registered, is_active, created_at, updated_at
  FROM yamf.user
  WHERE user_id = :userId OR username = :username
`
// Note: internal fields (hash, salt) excluded from SELECT
```

### Read (List/Search)

```javascript
// Generated validator for list queries
const validateList = createValidator({
  // Pagination
  limit: is(is.optional, is.int({ min: 1, max: 100 })),
  offset: is(is.optional, is.int({ min: 0 })),
  
  // Sorting
  orderBy: is(is.optional, is.oneOf('userId', 'username', 'createdAt', 'updatedAt')),
  orderDir: is(is.optional, is.oneOf('asc', 'desc')),
  
  // Filtering (auto-generated from searchable fields)
  username: is(is.optional, is.string()),  // partial match
  isActive: is(is.optional, is.bool),
  isRegistered: is(is.optional, is.bool),
}, { name: 'ListUsers' })
```

### Update

```javascript
// Generated validator - requires primary key + at least one field to update
const validateUpdate = createValidator(
  is.refine(
    is.object({
      userId: userSchema.fields.userId.type,  // required
      username: is(is.optional, userSchema.fields.username.type),
      isRegistered: is(is.optional, userSchema.fields.isRegistered.type),
      isActive: is(is.optional, userSchema.fields.isActive.type),
    }),
    (data) => Object.keys(data).length > 1,  // more than just userId
    'At least one field to update is required'
  ),
  { name: 'UpdateUser' }
)

// Generated query uses COALESCE for partial updates
const updateQuery = `
  UPDATE yamf.user
  SET
    username = COALESCE(:username, username),
    is_registered = COALESCE(:isRegistered, is_registered),
    is_active = COALESCE(:isActive, is_active),
    updated_at = :updatedAt
  WHERE user_id = :userId
  RETURNING user_id, username, is_registered, is_active, created_at, updated_at
`
```

### Delete

```javascript
// Hard delete
const deleteQuery = `DELETE FROM yamf.user WHERE user_id = :userId`

## API Design

  // Optional hooks

    beforeCreate: async (data, context) => {
      // Hash password before storing

    },
    afterCreate: async (result, context) => {
      // Send welcome email, etc.
    },
    beforeUpdate: async (data, context) => {
      // Validate business rules
    },
    beforeDelete: async (id, context) => {
      // Check dependencies
    },
  },
  
  // Custom actions (extend beyond CRUD)
  actions: {
    register: {
      validator: validateRegister,
      handler: async (sql, data) => { /* ... */ },
    },

      validator: validateChangePassword,
      handler: async (sql, data) => { /* ... */ },

```

### Service Interface

```javascript
// All generated services expose consistent action patterns
await callService('user-service', { create: { username, password } })
// Pending invites: `invite: { username? }` (no password)
await callService('user-service', { get: { userId } })
await callService('user-service', { list: { isActive: true, limit: 10 } })
await callService('user-service', { update: { userId, isActive: false } })
await callService('user-service', { remove: { userId } })

// Custom actions

await callService('user-service', { changePassword: { userId, newPassword } })
```

## Query Generation Strategy

### Template Generation

Rather than string interpolation, generate parameterized query templates:

```javascript
function generateInsertQuery(schema) {
  const fields = Object.entries(schema.fields)
    .filter(([_, def]) => !def.autoIncrement)
    .map(([name, def]) => ({
      field: name,
      column: def.column || camelToSnake(name),
    }))
  
  const columns = fields.map(f => f.column).join(', ')
  const placeholders = fields.map(f => `:${f.field}`).join(', ')
  
  const returningFields = Object.entries(schema.fields)
    .filter(([_, def]) => !def.internal)
    .map(([_, def]) => def.column || camelToSnake(_))
    .join(', ')
  
  return `
    INSERT INTO ${schema.tableName} (${columns})
    VALUES (${placeholders})
    RETURNING ${returningFields}
  `
}
```

### Dynamic WHERE Clauses

For flexible filtering in list operations:

```javascript
function generateWhereClause(filters, schema) {
  const conditions = []
  const params = {}
  
  for (const [field, value] of Object.entries(filters)) {
    const def = schema.fields[field]
    if (!def) continue
    
    const column = def.column || camelToSnake(field)
    
    if (typeof value === 'string' && def.type.type === 'string') {
      // Partial match for strings
      conditions.push(`${column} ILIKE :${field}`)
      params[field] = `%${value}%`
    } else {
      // Exact match for others
      conditions.push(`${column} = :${field}`)
      params[field] = value
    }
  }
  
  // Handle soft delete
  if (schema.softDelete) {
    conditions.push(`${schema.softDelete.column} IS NULL`)
  }
  
  return {
    clause: conditions.length ? `WHERE ${conditions.join(' AND ')}` : '',
    params,
  }
}
```

## Security Considerations

1. **Input Validation**: All inputs validated before query execution
2. **Parameterized Queries**: No string interpolation in SQL
3. **Internal Fields**: Sensitive fields (hash, salt) never exposed in responses
4. **Case Mapping**: Output automatically converted to camelCase, preventing manual handling errors
5. **Placeholder Validation**: Only valid identifiers allowed as placeholders (`/^[a-zA-Z_][a-zA-Z0-9_]*$/`)
